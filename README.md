# Socolata Injector

Modern Windows x64 DLL / JAR injector with multiple injection methods.

## Features

- **Native Inject** (LoadLibrary)
- **Manual Map**
- **SetWindowsHook**
- **Valorant Hook** (specific window detection)
- **JAR Injection**
- Process icon + architecture detection (x64 / x86)
- Multiple file support (DLL + JAR)
- Advanced settings (Erase PE, Stealth, Delay, etc.)
- Live log
- Clean modern GUI

## Requirements

- Windows 10 / 11 (x64)
- Visual Studio 2022 or newer
- Run as Administrator

## Build

1. Open the project in Visual Studio
2. Set configuration to **Release** + **x64**
3. Set SubSystem to **Windows**
4. Build

## Usage

1. Run the injector as Administrator
2. Type the target process name (e.g. `notepad.exe`)
3. Add one or more DLL / JAR files
4. Choose injection method
5. Click the corresponding button
